region of attraction:
def: let \(x_e\) be an equilibrium point of \(\dot x = f(x), x \in \mathbb{R}\). then the region of attraction is \(R_A(x_e)=\{x_0\in\mathbb{R}^n|\lim_{t\rightarrow \infty}x(t,x_0)=x_e\}\).

  • note: \(R_A\) may be hard to compute exactly, so a valid question is how to estimate it.
    suppose we are given:
  • \(D \subset \mathbb{R}^n\), D open, \(x_e=0 \in D\)
  • \(\dot x = f(x),\) locally Lipschitz on D, f(0)=0
  • \(V:D\rightarrow\mathbb{R}\) continusouly differentiable, \(V(x)>0\)
  • \(\dot V:D\rightarrow\mathbb{R}\), \(\dot V(x)<0\)

seek: \(c>0\) s.t. \(\Omega_c:=\{x\in D | V(x) \le x \}\) is compact for then by proof of lyapunov stability theorem, \(\forall x_o \in \Omega_c, \lim_{t \rightarrow 0}x(t,x_0)=0\) (i,e, \(\Omega_c \subset R_A\))

  • note that compactness \(\iff\) closed and bounded
    remark: suppose \(D=B_r(0)\). then, \(\Omega_c:=\{x\in B_r(0) | V(x) \le c \}\) is automatically bounded. it will be closed if \(\{x\in \bar B_r(0) | V(x) \le c \}\subset B_r(0)\)

  • consider \(V(x)=x^\top Px,P==P^\top\)
  • fact: \(\lambda_\min x^\top x \le x^\top Px \le \lambda_\max x^\top x\)

time-varying systems

\(V:\mathbb{R}^n\rightarrow \mathbb{R}\) is pos. def. if \(V(0)=0,V(x)>0,\forall x \not = 0\)
\(V:\mathbb{R}^n \rightarrow \mathbb{R}\) is locally pos. def. if \(V(0)=0 \& \exists r>0,V:B_r(0)\rightarrow\mathbb{R}\) is p.d.f.
V is neg. def. if -V is pos. def.

\(\dot x=f(t,x)\) \(\rightarrow\) time-varying system

what is the eq. point? \(\dot x |_{x_e}=0 \space \forall \space t\ge t_0\)

problems of time-varying systems:

\(\dot x = f(t,x), f(t,x_e)=0\space \forall \space t\ge t_0, x(t_0)=x_0\)

(a) suppose A.S. the region of attraction depends on \(t_0\). what could cause a problem is that we have \(R_A\rightarrow \{x_e\}\) as \(t_0\rightarrow \infty\) because \(R_A\) depends on \(t_0\).
(b) another problem is that non-intuitive Lyapunov results in
\(V(t,x)=0\forall \space t\ge t_0, V(t,x)>0\forall \space t\ge t_0,\forall x \not = x_e, \dot V(t,x)\le 0, \forall \space t\ge t_0, \forall x\)

  • \(\not \implies x_e\) is AS despite intuition
  • look at timevaryingsystems.pdf

example 2: \(\dot x= x, x\in \mathbb{R}\) (LTI) \(x_e=0\) is unstable

\(V(t,x)=e^{-3t}x^2\)

  • \(V(t,0)=0, \forall t \ge t_0\)
  • \(V(t,x)>0,\forall t, \forall x \not = 0\)
  • \(\dot V(t,x)=\frac{d}{dt}V(t,x)=\frac{\partial V}{\partial t}+\frac{\partial V}{\partial x}\frac{dx }{dt}\)
  • = \(-3e^{-3t}x^2+2x^2e^{-3t}=-e^{-3t}x^2\)
  • this is strictly \(<0\forall x \not =0, \forall \space t\ge t_0\)
  • \(\implies\) ~~GAS~~ because eq. pt. is unstable
    • V decreases with time
    • can we upper/lower bound V? for time-varying

\(\dot x = f(t,x),x(t_0)=x,f(t,0)-0, \forall t \ge 0\)

  • \(x_e=0\) is SISL \(\forall \varepsilon>0,\exists \delta(\varepsilon,t_0)>0\) s.t. \(||x_0||<\delta \implies ||x(t)||<\varepsilon,\forall \space t\ge t_0\)
  • \(x_e=0\) is uniformly stable (SISL) if \(\forall \varepsilon >0 \exists \delta(\varepsilon)>0\) independent of \(t_0\).
    • s.t. \(||x_0||<\delta \implies ||x(t)||<\varepsilon\)
  • \(x_e\) is unstable otherwise
  • \(x_e\) is AS if it is SISL & \(\exists C(t_0)>0\) s.t. \(x(t)\rightarrow 0\) as \(t \rightarrow \infty \forall ||x_0||<c\)
  • \(x_e\) is uniformly AS if it is uniformly stable & \(\exists C>0\) independent of \(t_0\)
    • s.t. \(x(t)\rightarrow 0, t\rightarrow \infty,\forall ||x_0||<C\)
  • \(x_e\) is globally uniformly AS if it is uniformly AS \(\forall C>0\)
