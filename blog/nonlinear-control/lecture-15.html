example:
\(\Sigma_a:\dot x = x\zeta; \dot \zeta = u\)
come up with some controller for original system
\(\Sigma : \dot x = xu; f(x)=0,g(x)=0\)

first, design controller for \(\alpha(x)\)
choose \(\alpha(x)=-x^2\implies \dot x = -x^3\)
for proof of stability, \(V(x) = x^2/2\implies \dot V = -x^4<0\)

for \(\Sigma_a\rightarrow u=-c(\zeta+x^2)+\frac{\partial \alpha}{\partial x}(f+g\zeta)\)
\(= -c(\zeta+x^2)+-2x(x\zeta)-x^2\)

  • \(L_{f+g\zeta}=\frac{\partial \alpha}{\partial x}(f+g\zeta)\)
  • \(L_gV(x)=\frac{\partial V}{\partial x}g(x)\)
    \(V_a=V(x)+\frac{1}{2}(\zeta+x^2)^2\implies \dot V_a<0\)

try a different alpha:
\(\alpha(x)=0\implies \dot x = 0\)
\(V(x)=\frac{1}{2}x^2\implies \dot V(x) =0\le 0\)
for \(\Sigma_a:V_a=V(x)+\frac{1}{2}(\zeta+x)^2=V(x)+\frac{1}{2}(\zeta)^2\)
\(\dot V_a=x \dot x + \zeta \dot \zeta=x(x\zeta)+\zeta u=\zeta[x^2+u]\)
\(u=-x^2-c\zeta\)
\(\dot V_a=-c\zeta^2\le0\implies\) SISL for \(x=0,\zeta=0\)

apply lasalle's theorem to check for further stability
\(S=\{(x,\zeta)|\dot V_a=0\}=\zeta=0\)
is the origin the only solution within this set?
\(\dot \zeta = 0=-x^2-c\zeta\implies x=0\)
by lasalle's (and also radially unbounded) we have GAS

strict feedback systems
def: a system that can be expressed in the following form:
\(\dot x = f_0(x)+g_0(x)\zeta_1\)
\(\dot \zeta_1 = f_1(x,\zeta_1)+g_1(x,\zeta_1)\zeta_2\)
\(\dot \zeta_2= f_1(x,\zeta_1,\zeta_2)+g_1(x,\zeta_1,\zeta_2)\zeta_3\)
\(\vdots\)
\(\dot \zeta_k= f_k(x,\zeta_1,\zeta_2,\dots,\zeta_k)+g_k(x,\zeta_1,\zeta_2,\dots,\zeta_k)u\)
where \(x\in\mathbb{R}^n, \zeta_i \in \mathbb{R}, u\in\mathbb{R}\)
\(f_1(0,0)=0,f_2(0,0,0)=0,\dots,f_k(0,\dots,0)=0\)
and x dynamics satisfies assumption A1 (see prev. lecture)

is called a strict feedback system

what do the \(\zeta\)'s look like?

\(\dot x = f_0(x)+g_0(x)\zeta_1 \rightarrow \zeta_1=\alpha(x),V(x),\alpha(0)=0\)
\(\dot \zeta_1=f_1(x,\zeta)+g_1(x,\zeta_1)\zeta_2\rightarrow \zeta_2=\alpha_1(x,\zeta_1),V_1(x,\zeta_1)=V(x)+\frac{1}{2}[\zeta_1-\alpha(x)]^2\)
\(\dot\zeta_2=f_1(x,\zeta_1,\zeta_2)+g_1(x,\zeta_1,\zeta_2)\zeta_3=\alpha_2(x,\zeta_1,\zeta_2),V_2(x,\zeta_1,\zeta_2)=V_1(x,\zeta_1)+\frac{1}{2}[\zeta_3-\alpha_2(x,\zeta_1)]^2\)
\(\vdots\)
\(\dot V_2=\frac{\partial V_2}{\partial x}\dot x+\frac{\partial V_2}{\partial \zeta_1}\dot \zeta_1+\frac{\partial V_2}{\partial \zeta_2}\dot \zeta_2\)

  • and recall \(\dot \zeta_2=\zeta_3\)

sliding mode control aka variables structure systems

\(\iff\ddot y +ky=0\)
we want to find if we can pick \(k=\pm1\) with the goal of \(y \rightarrow 0\)
pick two states: \(x_1=y,x_2=\dot y\implies \dot x_1=x_2,\dot x_2=-kx_1\)

\(k=+1:\)
draw phase-space plot
\(\frac{\dot x_1}{\dot x_2}=\frac{\frac{dx_1}{dt}}{\frac{dx_2}{dt}}=\frac{dx_1}{dx_2}=\frac{-x_2}{x_1}\)
\(x_1dx_1+x_2dx_2=0\)
\(\frac{x_1^2}{2}+\frac{x_2^2}{2}=c\) becomes circles corresponding to c
\(\rightarrow\) SISL

\(k=-1:\)
\(\frac{dx_1}{dx_2}=\frac{x_2}{x_1}\iff x_1dx_1=x_2dx_2=0\)
\(\frac{x_1^2}{2}-\frac{x_2^2}{2}=c\) becomes parabolas approaching \(\infty\) in all directions
\(\rightarrow\) unstable

\(\therefore k=\pm 1\rightarrow\) no convergence to \((0,0)!\)

if we switch between \(\pm\), could we drive the system to \((0,0)\)?


\(x_2=-ax_1,0<a<1\)
where the line is \(s=ax_1+x_2=0\)

  • above the line, \(s>0,\) and below \(s<0\)
  • \(k=\text{sign}(sx_1)\), either -1 or +1 depending on side of line
  • switches from circle to parabola depending on k
