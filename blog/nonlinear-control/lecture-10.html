Lecture 10: Class K Functions, Uniform and Exponential Stability

Nonlinear Control Notes · Feb 26, 2026

{% raw %}

problems with TV nonlinear systems:
(1) properties depend on \(t_0\)

  • rate of convergence
  • region of attraction (\(R_A\rightarrow x_e,t_0\rightarrow \infty\))
    (2) non-intuitive lyapunov conditions
  • \(\dot x = x\) where \(V(x)\not \implies\) SISL

redefine what positive definiteness is for a lyapunov function

definition: a continuous function \(\alpha:[0,a)\rightarrow[0,\infty)\) is scalar and a class K function if it is strictly increasing and \(\alpha(0)=0\). \(\alpha\) is class \(K_\infty\) if \(a=\infty\) aka defined for all \(a\in \mathbb{R}>0\).

definition: \(V:[0,\infty)\times \mathbb{R}^n\rightarrow \mathbb{R}\) is locally positive definite if it satisfies:

  1. \(V(t,0)=0\forall t \ge 0\)
  2. \(\exists r>0\) and a class K function \(\alpha:[0,r)\rightarrow[0,\infty)\) s.t. \(V(t,x)\ge\alpha(||x||),\forall t \ge 0, \forall x\in B_r(0)\) (\(\alpha\) does not depend on time)
    in summary, lower bounded by some time-independent function (class k)

definition: a continuous function \(V:[0,\infty)\times\mathbb{R}^n\rightarrow\mathbb{R}\) is decrescent if \(\exists \sigma >0\) and a class k function \(\gamma:[0,\sigma)\rightarrow[0,\infty)\) s.t. \(V(t,x) \ge \gamma(||x||),\forall t \ge 0, \forall x \in B_\sigma(0)\)
in summary, upper bounded by some time independent (decrescent) function.

examples

  1. \(w(x_1,x_2)=x_1^2+x_2^4\)
    • globally positive definite
    • decrescent (can we find a function that upper bounds it?)
  2. \(w(x_1,x_2)=x_1^8\)
    • not locally positive definite (for \(x_1=0\))
    • decrescent
  3. \(w(x_1,x_2)=x_1^2+(\sin(x_2))^2\)
    • locally positive definite
    • decrescent
  4. \(w(x_1,x_2)=(x_1+x_2)^4\)
    • not positive definite
    • decrescent
  5. \(v(x_1,x_2,t)=\frac{1}{1+t}[x_1^2+x_2^2]\)
    • not positive definite because shrinks as \(t\rightarrow\infty\)
    • decrescent
  6. \(v(x_1,x_2,t)=(1+t)[x_1^2+x_2^2]\)
    • positive definite
    • not decrescent (\(t\rightarrow\infty\))
  7. \(v(x_1,x_2,t)=(3+\sin(t))[x_1^2+x_2^2]\)
    • positive definite
    • decrescent

fact: the following statements are equivalent

  1. \(V(t,x)\) is locally positive definite
  2. \(\exists W(x)\) locally positive definite s.t. \(V(t,x)\ge W(x),\space\forall\space t\ge 0, \forall x \in B_r(0)\)
  3. \(\bar W(x):=\inf_{t\ge0}V(t,x)\) is locally positive definite

theorem: consider \(\dot x=f(t,x),x(t_0)=x_0,f(t,0)=0,\forall t\ge 0\), f locally Lipschitz in x and p.w. continuous in t.

  1. then, \(x_e=0\) is (uniformly) SISL if \(\exists V \in C^1;V:[0,\infty)\times \mathbb{R}^n\rightarrow\mathbb{R}\) (decrescent), locally positive definite and \(\rho>0\) s.t. \(\dot V(t,x)\ge 0, \forall t \ge 0, \forall x \in B_\rho(0)\).
  2. \(x_e=0\) is (uniformly) AS if \(\exists V \in C^1\) (decrescent) locally positive definite and \(-\dot V\) is locally positive definite.

exponential stability
consider \(\dot x = f(t,x), f(t,0)=0\forall t \ge 0\). def: \(x_e=0\) is exponentially stable if \(\forall t_0\ge 0,\exists \sigma>0,\gamma>0,N<\infty\) s.t.

  1. \(\forall x_0 \in B_\sigma(0),x(t,t_0,x_0)\) exists on \([t_0,\infty)\) and is unique
  2. \(||x(t,t_0,x_0)|| \le N||x_0||e^{-\gamma t}, \forall t \ge t_0,x_0 \in B_\sigma(0)\)
    if, in addition, \(\sigma,\gamma, N\) are independent of \(t_0\), then the origin is uniformly exponentially stable.
  • ES \(\implies\) AS \(\implies\) SISL
  • uniform ES \(\implies\)uniform AS \(\implies\) uniform SISL

example: \(\dot x= -x^3\)

  • globally AS

\(\dot x= -x^3+1^{-10}x\)

  • via indirect method, we can take jacobian:
  • \(A=\frac{\partial f}{\partial x}_{x=0}=1^{-10}>0\implies\) unstable eigenvalue
  • AS is fragile under small linear perturbations
    • this is prevented with ES conditions

theorem: suppose \(x_e=0\) is an eq. point of \(\dot x= f(t,x)\), f is Lipschitz in x, p.w. continuous in t. then, a sufficient condition for \(x_e=0\) is uniformly ES is:

  • \(\exists V:[0,\infty)\times\mathbb{R}^n\rightarrow \mathbb{R}\) (Lyapunov function) and \(\alpha, \beta, \gamma>0\) s.t. \(\forall x \in B_r(0),\forall t \ge 0\)
  • a) \(\beta x^\top x \ge V(t,x) \ge \alpha x^\top x\implies\) locally positive definite and decrescent
  • b) \(\dot V(t,x) \le \gamma V(t,x)\)
    • \(\implies V(t,x(t)\le e^{-\gamma t}V(t,x_0)\)
  • this is comparable to Lyapunov direct method

comparable to Lyapunov indirect method ...

theorem: (key for all of linear control)
consider a time-invariant NL system \(\dot x = f(x),f(0)=0,x\in \mathbb{R}^n\) . \(x_e=0\) is ES \(\iff\) all eigenvalues of \(A=\frac{\partial f }{\partial x}|{x=0}\) have negative real parts.
