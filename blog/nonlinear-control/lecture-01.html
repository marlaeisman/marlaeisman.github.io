math background

  1. fields (\(R, C\))

  2. vector space (\(R^n\))

  3. \(R = R_e=-\infty \cup R \cup \infty\)

  4. supremum (least upper bound: let \(S \subset R\), an element of \(a \in R_e\) is the supremum of \(S\) if

    • \(s\leq a \forall s \in S\) (a is an upper bound)

    • if \(b \in R_e\) satisfies \(s \leq b \forall s \in S\), then \(a \leq b\) (least upper bound)

    • notation: \(a =\sup S\)

    • maximum: if \(S\subset R\) and \(\sup S \in S\) then \(\bbox[#e0daf7, 5px]{\max S = \sup S}\).

      example:

      • S=(0,1) : \(\sup S = 1\), max DNE
      • S=(0,1]: \(\sup S = \max S =1\)
      • \(S=[x \geq 0 \mid x \in R]\): \(\sup S = + \infty\), max DNE

    • infimum (greatest lower bound): \(S \subset R, \inf S=C \in R_e\)

      • \(s\geq c, \forall s \in S\)
      • if \(d \in R_e\) satisfies \(s \geq d \forall s \in S\) then \(c \geq d\)

    suppose \(s \subset R, f:s\rightarrow R\)

    • \(\sup f(x) := \sup [f(x) \mid x \in S]\) (\(\subset R\))

  5. norms: let V be a vector space over the reals R then \(\mid \mid x \mid \mid : V \rightarrow R\) is a norm if
    a) \(\forall x \in V, \mid \mid x \mid \mid \geq 0\) and \(\mid \mid x \mid \mid = 0 \implies x=0\)
    b) \(\forall x \in V, \alpha \in R,\mid \mid \alpha V \mid \mid = \mid \alpha \mid \mid \mid v \mid \mid\)
    c) \(\forall x, y \in V, \mid \mid x+y\mid \mid \leq \mid \mid x\mid \mid + \mid \mid y \mid \mid\) (triangle ineq)

    def: \((V, \mid \mid \cdot \mid \mid)\) is a norm space if V is a vector space over R & \(\mid \mid \cdot \mid \mid:V\rightarrow R\) is a norm

    • example:
    • a) \(V \rightarrow R^n\),
      • \(\mid \mid x \mid \mid _2 = \sqrt{\sum x_i^2}\)
      • \(\mid \mid x \mid \mid _1 = \sum x_i^2\)
      • \(\mid \mid x \mid \mid _\infty = \max x_i\)
    • b ) \(V = [f:[a,b]] \rightarrow R \mid f\) is continuous (\(\subset [a,b]\))
      • \(\mid \mid f \mid \mid _\infty = \max_{a\leq x \leq b} \mid f(x) \mid\)

  6. induced norm: let \(A:V\rightarrow V\) be a linear operator and (\(v, \mid \mid \cdot \mid \mid\)) be a normed space. The induced norm of A is \(\mid \mid A \mid \mid_i := \sup \frac{\mid \mid Ax \mid \mid}{\mid \mid x \mid \mid} = \sup_{\mid \mid x \mid \mid = 1}\mid \mid Ax \mid \mid\).

    • note: type of norm does not matter
    • \(\mid \mid Ax \mid \mid \leq \mid \mid A \mid \mid \mid \mid x \mid \mid \forall x \in V\)
    • if we map x through A, it can map anywhere
      • typically an ellipsoid corresponding to Ax
      • for each point, we are finding norm and sup of that norm which is the induced norm
      • what is the maximum we can stretch this unit circle?
    • \((V, \mid \mid \cdot \mid \mid)=(R^n,\mid \mid \cdot \mid \mid_2)\)
    • \(\mid \mid A \mid \mid_i = \sqrt{\lambda_{\max}(A ^{\top}A)}\)

    def: two norms \(\mid \mid \cdot \mid \mid \& \mid \mid \cdot \mid \mid\) on V are equivalent if \(\exists\) constants \(k_1, k_2 > 0 \text{ s.t. } \forall x \in V, k_1 \mid \mid x \mid \mid \leq \mid \mid \mid x \mid \mid \mid \leq k_2 \mid \mid x \mid \mid\)

    • fact: V is finite dimensional if and only if all norms on V are equivalent

  7. open sets & open balls

    • let \(x_0 \in V, (V,\mid \mid \cdot \mid \mid)\) is a normed space & \(a \in R,a>0\).

    • then \(B_a(x_0):=[x \in V \mid \mid \mid x-x_0 \mid \mid < a]\) is an open ball of radius a centered at \(x_0\)
      example: \((R^2 \mid \mid \cdot \mid \mid_2) B_1(0)\)

      • this is a unit circle and the space inside of it.
      • circumference is not included

    • \((R^2,\mid \mid \cdot \mid \mid_1)\) where \(\sum x_i < 1\)

      • becomes a diamond (edge not included)

    • (\(R^2 \mid \mid \cdot \mid \mid_\infty\))

      • this becomes a square (edge not included)

  • open set: A set \(s \in V\) is open if \(\forall s_0 \in S, \exists \varepsilon > 0 \mid B_\varepsilon(s_0) \subset S\).

    • by convention, the empty set is open.

    example:

    • \(S=(0,1)\subset(R,\mid \cdot \mid)\) is open
    • \(S=[0,1)\subset(R,\mid \cdot \mid)\) is not open because \(s_0=0,\forall \varepsilon >0, B_\varepsilon \not \subset S\)
      • note: not open \(\not \implies\) closed
    • def: \(S \subset V\) is closed if ~\(S\) (complement) is open. \(\star \star \star\)
      • example: \([0,1] \subset R\), ~\(S=(-\infty,0)\cup(1,\infty)\)
      • example: \(S=[0,1) \subset R\), ~\(S=(-\infty,0) \cup [1,\infty)\) (not closed)
    • fact: arbitrary unions of open sets are open
      • arbitrary intersections of closed sets are closed
  1. convergences of sequences:
    • def: a sequence \(x_k\) in \((V, \mid \mid \cdot \mid \mid)\) converges to a point \(\bar x\) if:
      • \(\forall \varepsilon > 0 \exists N< \infty\) s.t. \(\forall K \geq N, ||x_k-\bar x|| < \varepsilon\)
        • note: \(||x_k-\bar x|| < \varepsilon\) is \(x_k \in B_\varepsilon(\bar x)\)
        • if \(\exists\) some k=N along the x axis , \(x_k=\bar x\) on y axis intersects it where N is a function of \(\varepsilon\).
        • after we pass N, all points are within the ball (this is the sequence converging)

examples:

  1. \((V, ||\cdot ||=(R, |\cdot |)\)
  • \((x_n),x_n=\frac{1}{n},\bar x=0\)
    • \(\lim_{n\rightarrow \infty}x_n = \bar x\)
  • \((x_n),x_n=(1+\frac{1}{n})^n,\bar x =e\)
