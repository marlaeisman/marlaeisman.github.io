def: global asymptotic stability

  • \(x=0\) is GAS if it is SISL & \(\forall x_0 \in \mathbb{R}^n\), \(x(t,x_0)\) exists on \([0,\infty)\) & \(\lim_{t \rightarrow \infty}x(t,x_0)=0\).
  • we know that for AS, \(\dot V(x) < 0; x\not = 0\), so for GAS...
    theorem: \(\dot x= f(x),f(0)=0\). let \(V:\mathbb{R}^n \rightarrow \mathbb{R},V \in C^1\) s.t.
    (i) \(V(0)=0,V(x)>0,x\not = 0\)
    (ii) \(V(x) \rightarrow \infty\) as \(||x|| \rightarrow \infty\) (V is radially unbounded)
  • in some cases, this captures observability
    (iii) \(\dot V (x)<0 \forall x \in \mathbb{R}^n, x\not = 0\)
    then \(x_e=0\) is GAS.

radially unbounded is unique... why do we do this?

  • look at \(x \in \mathbb{R}^2\)
    \[V(x)=\frac{x_1^2}{1+x_1^2}+x_2^2\]
    (i) \(V(0)=0\)
    (ii) is not satisfied
    (iii) assume satisfied

example:mass spring damper cart (nonlinear spring \(k(x)\))

  • \(|x|<d;xk(x)>0\space \& \space k(0)=0\)
  • \(m\ddot x+b\dot x +k(x)=0\)
  • \(x_1=x;x_2 =\dot x\implies\)
    \[\begin{bmatrix} \dot x_1 \\ \dot x_2 \end{bmatrix} = \begin{bmatrix} x_2 \\ -b/m\cdot x_2 - 1/m \cdot k(x) \end{bmatrix} \]
    \[x_e = \begin{bmatrix} 0 \\ 0 \end{bmatrix} \]
  • in general, we can see this is asymptotically stable within d bounds (local)
  • candidate Lyapunov function: \(V(x) = KE+PE\)
    • \(KE=\frac{1}{2}mx_2^2\)
    • \(PE=\int^{x_1}_0k(\sigma)d\sigma\)
    • \(V(x)=\frac{1}{2}mx_2^2+\int^{x_1}_0k(\sigma)d\sigma\)
  • we can now check if it satisfies conditions
    • \(V(0)=V(0,0)=0\)
    • \(V(x)>0; x\not =0\because x_1k(x)>0\)
      • \(D=[x||x_1|<d]\)
    • \(\dot V(x_1,x_2)=\frac{\partial V}{\partial x_1}\dot x_1 + \frac{\partial V}{\partial x_2}\dot x_2\)
      • \(=k(x_1)x_2-bx_2^2-k(x_1)x_2\)
      • \(=-bx_2^2\le 0\)
      • NOT: \(\dot V(x)<0\) for \(x=0\)
      • \(x_e=0\) is SISL
        • this contradicts intuition... so we can
          • (i) find a better Lyapunov function
            • from 4.5 khalil \(\rightarrow\) \(W(x_1,x_2)=\frac{1}{m}\int^{x_1}_0k(\sigma)d\sigma\) \[+\begin{bmatrix} x_1 \\ x_2\end{bmatrix} \begin{bmatrix} (1/2)(b/m)^2 & (1/2)(b/m) \\ (1/2)(b/m) & 1 \end{bmatrix} >0\] (positive definite)
          • (ii) find a better theorem to conclude AS
            • proof: Lasalle's theorem: \(\dot x=f(x),f(0)=0,f\) is locally Lipschitz, \(x\in \mathbb{R}^n\). Assume there exists open set D containing \(x_e=0\) & exists \(V:D\rightarrow \mathbb{R},V\in C^1\) s.t.
            • (1) \(V(0)=0,V(x)>0,x\not - 0, x \in D\)
            • (2) \(\dot V(x) \le 0, x\in D\)
            • let \(S=[x \in D | \dot V(x)=0]\). suppose only function \(\phi:[0,T]\rightarrow \mathbb{R}^n\) that satisfies
            • (3) \(\dot \phi (t) = f(\phi(t))\implies\) (\(\phi\)) is a solution
            • (4) \(\phi(t) \in S \forall t\ge 0\) is \(\phi(t)\equiv x_e = 0\)
            • them \(x_e\) is AS (only the eq point)

now, can we apply Lasalle's to the example function:
\(V(x)=\frac{1}{2}mx_2^2+\int^{x_1}_0k(\sigma)d\sigma;\space \dot V(x)=-bx_2^2\)
construct \(S=[x\in D|\dot V(x)=0]=[x\in \mathbb{R}^2| |x_1|<d,x_2=0]\)
let \[\phi(t)=\begin{bmatrix} \phi_1(t) \\ \phi_2(t) \end{bmatrix} \] be a solution of the system that lies in \(S\forall t \ge 0\implies \phi_2(t)\equiv 0,|\phi_1(t)|<d\)
based on the dynamics, \(\dot \phi_2(t)|_s=-\frac{b}{m}\not \phi)2(t)-\frac{1}{m}k(\phi_1(t))\implies -\frac{1}{m}k(\phi_1(t)) = 0\)

  • \(\iff \phi_1(t)=0\)
  • the only solution is \(\phi_1=\phi_2=0=\implies x_e\) is AS

when is an equilibrium point unstable?

  • first, define where \(x_e=0\) is stable:
  • \(\forall \varepsilon>0\exists \delta>0\) s.t. \(\forall x_0 \space ||x||<\delta \implies ||x(t,x_0)||<\varepsilon \space \forall t \ge 0\)
  • definition: \(x_e\) is unstable if
  • \(\exists \varepsilon>0\forall \delta>0\) s.t. \(\exists x_0 \space ||x||<\delta \implies \space \exists T \ge 0 ||x(t,x_0)||>\varepsilon\)

instability theorem:

  • \(\dot x = f(x),f(0)=0\), f is locally Lipschitz
  • suppose \(\exists\) open set D containing \(x_e=0\)
  • and, \(V:D\rightarrow R\), V is \(C^1\) s.t.
    • (1) \(V(0)=0\)
    • (2) \(V(x)>0,x\not =0, x \in D\)
    • (3) \(\dot V(x)>0,x\not = 0,x \in D\)
  • \(\therefore x_e=0\) is unstable.

Chetaev's instability theorem:

  • let \(x_e=0\) be an eq. pt. of \(\dot x = f(x)\)
  • suppose \(\exists\) open neighborhood around \(x_e\) on which f is locally Lipschitz and \(\exists V:D\rightarrow\mathbb{R},V\in C^1\) s.t
  • (a) \(V(0)=0\)
  • (b) \(\forall \delta>0,\exists x_0 \in B_\delta(0)\) s.t. \(V(x_0)>0\)
  • (c) \(\exists \varepsilon>0\) s.t. \(\dot V(x)>0\) on \(U=[x\in B_\varepsilon(0)|V(x)>0]\subset D\)
    then, \(x_e=0\) is unstable
