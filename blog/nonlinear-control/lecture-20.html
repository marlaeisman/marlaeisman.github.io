Lecture 20: Vector Fields, Lie Brackets and Involutive Distributions

Nonlinear Control Notes · Apr 16, 2026

{% raw %}

question: when does \(\exists h(x)\) with relative degree n?

(a) manifold
(b) tangent space (tangent to pt. in manifold)
(c) tangent vector (some vector in TS)
(d) vector field
(e) tangent bundle

all contained within Lie Bracket

(f) distribution

all contained in involutive distribution

vector field
definition: vector field f on manifold M is an assignment to each point \(p \in M\) a vector \(f(p)\in T_pM\) (vector space). vector field \(C^k\) if f is \(C^k\) (cont. diff).

Lie bracket:
f, g are vector fields. the Lie bracket is defined as \([f,g](x)=\frac{\partial g}{\partial x}f(x)-\frac{\partial f}{\partial x}g(x)\)
\(=L_fg(x)-L_gf(x)\)

  • at each point on the vector field, it returns a manifold

example:
\[f(x)= \begin{bmatrix} x_2 \\ -\sin x_1 -x_2 \end{bmatrix}, g(x) = \begin{bmatrix} 0 \\ x_1 \end{bmatrix} \]
\([f,g]=L_fg-L_gF= \frac{\partial g}{\partial x}f(x)-\frac{\partial F}{\partial x}g(x)\)
\[=\begin{bmatrix} 0 \\ x_2 \end{bmatrix} - \begin{bmatrix} x_1 \\ -x_1 \end{bmatrix} \]
\[= \begin{bmatrix} -x_1 \\ x_1+x_2 \end{bmatrix} \]
\([f,[f,g]](x)=?\)
\([f,[f,[f,[f,g]]]](x)=?\)
.... we can continue doing this because each of these are vector fields

this is denoted with adjoint:
\(\text{ad}_fg(x):=[f,g](x)\)
\(\text{ad}^2_fg(x)=[f,\text{ad}_fg(x)](x)=[f,[f,g]](x)\)
\(\vdots\)
\(a_f^kg(x)=[f, \text{ad}_f^{k-1}g(x)](x),k\ge 1\)
\(\text{ad}^0_fg(x)=g(x)\)
note:
(i) \([f,f](x)=0\)
(ii) \([f,g](x)=-[g,f](x)\)
(iii) f,g are const. vectors

  • \([f,g]=0\)

example: \(\dot x = Ax+Bu\)
\(f(x) = Ax, g(x) = B\)
\(\text{ad}_fg(x)=[f,g]=L_fg-L_gF= \frac{\partial g}{\partial x}f(x)-\frac{\partial F}{\partial x}g(x)\)
\(=0-AB=-AB\)
\(\text{ad}^2_fg(x)=[f,[f,g]]=L_f[f,g]-L_{[f,g]}f=A^2B\)
\(\text{ad}^3_fg(x)=-A^3B\)
...
\(\text{ad}^k_fg(x)=[f,ad_f^{k-1}g]=(-1)^kA^kB\)

tangent bundle:
tangent bundle of M is \(TM:= \cup_{P\in M}T_p M\)

distributions:
suppose \(f_1, f_2, ..., f_n\) are vector fields and the distribution \(\Delta(x)=\space\{f_1(x),f_2(x), ...f_n(x)\}\) (all vectors).
at each particular x, \(\Delta(x)\) is a subspace of \(T_xM\)

definition: \(\Delta\) is a nonsingular distribution if \(\dim(\Delta(x))=\) const.

definition: \(\Delta\) is involutive if \(f,g \in \Delta \implies [f,g] \in \Delta\)
ex: \[f_1 = \begin{bmatrix} 2x_2 \\ 1 \\ 0 \end{bmatrix}, f_2 = \begin{bmatrix} 1 \\ 0 \\ x_2 \end{bmatrix}, \Delta = \text{span}\{f_1,f_2\} \]
is \(\Delta\) nonsingular?
\(\dim(\delta(x))=2=\) const

is \(\Delta\) involutive?
\([f_1,f_2]=[0 \space 0\space 1]^\top \in \Delta\) iff rank\([f_1(x), f_2(x), [f_1,f_2](x)]=2 \forall x\)
rank\(=3 \implies \Delta\) not involutive

theorem: \(\Sigma\) is FB linearizable iff
(a) \([g(x), \text{ad}_fg(x), ..., \text{ad}^{n-1}_fg(x)]\) has rank n \(\forall x\)
(b) \(\lambda = \text{span}\{g,\text{ad}_fg, ... \text{ad}^{n-2}_fg\}\) is involutive

system has relative degree n iff
(1) - \(L_gh=L_gL_fh=...=L_gL_f^{n-2}h=0 \space \forall x\)
(2) \(L_gL_f^{n-1}h \not = 0\)
\(\iff\)
(3) \(L_gh=L_{\text{ad}_fg}h=...L_{\text{ad}^{n-2}_fg}h=0 \space \forall x\)
(4) \(L_{\text{ad}^{n-1}_fg}h \not = 0\)

why convert it? advantage of (3) over (1) is that (3) can be written as:
\(\frac{\partial h}{\partial x}[g(x), \text{ad}_fg(x), ..., \text{ad}^{n-2}_fg(x)=0\)
solution \(h(x)\) for above PDE exists if \(\Delta=\{g, \text{ad}_fg, ..., \text{ad}^{n-2}_fg\}\) is involutive
