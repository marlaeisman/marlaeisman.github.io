Lecture 13: Sontag's Formula and the Small Control Property

Nonlinear Control Notes · Mar 12, 2026

{% raw %}

today: sontag control and backstepping

CLF for multi-input control affine system:
\(\dot x = f(x)+\Sigma^m_{i=1}g_i(x)u_i\)

V is a CLF if \(\forall x \not = 0\):
\[\inf_{u\in\mathbb{R}^m}\{L_fV(x)+\Sigma L_{g_i}V(x)u_i\}\]
if we want \(V(x)\) to not depend on the control input, all \(L_{g_i}\) must be zero.
\[\iff \forall x\not = 0,[L_{g_1}V(x),L_{g_2}V(x),...L_{g_m}V(x)]=[0,0,...,0]\implies L_f V(x)<0\]
example: \(\dot x = x + x^2 u, x; u \in \mathbb{R}\)

if we want AS for this system, for \(x>0\), \(x+x^2u<0\)
and for \(x<0\), \(x+x^2u<0\implies u<-1/x\)

for SISL, \(x+x^2u=0,u=-1/x\)
\(x \rightarrow 0 \implies |u|\rightarrow \infty\)

this is a Large control property

  • as we move closer to equilibrium, input moves towards infinity
  • we want to design for the opposite of this property

definition: a CLF V satisfies the small control property if \(\forall \varepsilon > 0, \exists \delta > 0\) s.t. \(\forall x \in B_\delta (0), x\not = 0, \exists u \in \mathbb{R}^m\) and \(\|u\|<\varepsilon\) s.t. \(\dot V(x) = L_fV + \Sigma L_{g_i}Vu_i <0\)

theorem (Sontag 1980s) single input case:
suppose \(V\) is a CLF for \(\dot x = f(x) + g(x)u; u\in \mathbb{R}, f(0)=0; f,g\) are Lipschitz, then

(1)
\[ u=\alpha_s(x)= -\frac{L_fV+\sqrt{(L_fV)^2+(L_gV)^4}}{L_gV(x)} \text{ for } L_gV\not=0 \]
\[ u=0 \text{ for else} \]
results in \(\dot V(x) = -\sqrt{(L_fV)^2+(L_gV)^4}<0, \forall x\not = 0 \implies x=0\) is GAS

(2) \(\alpha_s\) is continuous \(\forall x \not = 0\)

(3) \(\alpha_s\) is continuous at \(x = 0\) if CLF satisfies small control property

(4) finally, if \(V(x)\) is k+1 times continuously differentiable \(\forall x \not = 0\) then \(\alpha_s(x)\) is k times continuously differentiable \(\forall x \not =0\)

example: \(\dot x = \sin(x)-x^3+u,x\in\mathbb{R}, u\in \mathbb{R}\)
\(f(x)=\sin(x)-x^3, g(x)=1\)
candidate CLF: \(V(x)=\frac{1}{2}x^2\)

to find if this is a valid CLF...

  • compute Lie derivatives: check \(\forall x \not = 0, L_gV(x) =0 \implies L_fV(x)<0\)
  • \(L_gV(x)=\frac{\partial V}{\partial x}g(x)=x\)
  • \(L_gV(x)=0 \iff x=0\)
  • \(\implies\) condition is trivially satisfied \(\implies V(x)\) is a CLF

now we can make a sontag controller to achieve GAS

  • compute \(L_fV\)
  • \(L_fV(x)=\frac{\partial V}{\partial x}f(x)=x[\sin x - x^3]\)
    \[\alpha_s(x)=\begin{cases} -\frac{L_fV+\sqrt{(L_fV)^2+(L_gV)^4}}{L_gV(x)}, & L_gV\not = 0 \\ 0, & \text{else} \end{cases} \]
    \(\sqrt{x^2[\sin x - x^3]^2+x^4}\rightarrow\)
    \[\alpha_s(x)=\begin{cases} -\frac{x^2[\sin x - x^3]+\sqrt{x^2[\sin x - x^3]^2+(x)^4}}{x}, & x\not = 0 \\ 0, & \text{else} \end{cases} \]

\(\sqrt{x^2[\sin x - x^3]^2+x^4}= |x|\sqrt{[\sin x - x^3]^2+x^2}\rightarrow\)

\[\alpha_s(x)=\begin{cases} -{[\sin x - x^3]-\sin x\sqrt{(\sin x - x^3)^2+x^2}}, & x\not = 0 \\ 0, & \text{else} \end{cases} \]
is continuous at \(x=0\) and infinitely differentiable for \(x\not =0\)
\(\dot V (x) =-\sqrt{x^2(\sin x - x^3)^2+x^4}<0;\forall x \not =0\), \(x=0\) is GAS

many other controllers can make \(\dot V<0\)
\(\dot x= f(x)+g(x)\alpha(x)=:f_{CL}(x)\), \(V(x)=\frac{1}{2}x^2\)
\(\dot V(x)=\frac{\partial V}{\partial x}f_{CL}(x)=xf_{CL}(x)\)

(1) \(u=\alpha_1 x=\sin x + x^3-x\) (cancel out nonlinear terms aka feedback linearization)

  • \(\dot x = f_{CL}=-x\), \(\dot V = -x^2<0\implies\) GAS
    (2) \(u=\alpha_2(x)=\sin x -x\)
  • don't cancel the stabilizing nonlinearity (\(-x^3\))
  • \(\dot x = f_{CL}=-x^3-x\) is no longer linear
  • \(V(x)=-x^2-x^4<0\implies\) GAS
    (3) \(u=\alpha_3(x)=-\sin x\)
  • \(\dot x = f_{CL}=-x^3\)
  • \(\dot V = -x^4<0 \implies\) GAS
    (4) \(u=\alpha_4(x)=-2x\) (linear feedback that dominates destabilizing nonlinearity \(\sin(x)\))
  • \(\dot x = f_{CL}=\sin x - x^3-2x\)
  • \(\dot V = x \sin x -x^4-2x^2=x[\sin x-2x]-x^4\leq -x^2-x^4<0\implies\) GAS

\[\alpha_{\text{min-norm}}=\begin{cases} \frac{-L_fV}{L_gV}, & L_gV\not = 0 \\ 0, & \text{else} \end{cases}\]
