Lecture 12: Control Lyapunov Functions and Min-Norm Control

Nonlinear Control Notes · Mar 10, 2026

{% raw %}

control lyapunov functions

given: \(\dot x = f(x,u), x \in \mathbb{R}^n, u \in \mathbb{R}^m\)

  • \(f(0,0)=0, f(x_{eq},u_{eq}=0)\)
    problem: find \(\alpha:\mathbb{R}^n\rightarrow \mathbb{R}^m\) (full state feedback)
    s.t. \(x=0\) is GAS eq. pt. of the closed loop system \(\dot x = f(x,\alpha(x))\)

how do we find \(\alpha\)? aka full-state feedback?

observation: suppose there exists a solution to the previous state-feedback control problem, then (by converse lyapunov theorem) there exists a lyapunov function that maps the state to a scalar \(\exists V:\mathbb{R}^n\rightarrow \mathbb{R},V\in C^1\)

  • V is positive definite (\(V(0)=0,V(x)>0\forall x\not = 0\))
  • V is negative definite (\(\dot V <0 \forall x \not = 0\))
    • \(\iff \forall x \not = 0, \frac{\partial V}{\partial x}(x),f(x,\alpha(x))<0\)
    • can we remove dependence on alpha? \(\implies \forall x \not = 0, \exists u \in \mathbb{R}^n, \frac{\partial V}{\partial x}(x)f(x,u)<0\)
      • could take \(u=\alpha(x)\)
    • \(\iff \forall x \not = 0,\inf_{u\in\mathbb{R}^n}\frac{\partial V}{\partial x}(x)f(x,u)<0\)
  • V is radially unbounded

definition: control lyapunov function (CLF)
a continuously differentiable, positive definite, radially unbounded function \(V:\mathbb{R}^n \rightarrow \mathbb{R}\) is a CLF for \(\dot x = f(x,u),x\in \mathbb{R}^n, u\in \mathbb{R}^m\) if satisfies \(\forall x \not = 0, \inf_{u\in \mathbb{R}^m}\{\frac{\partial V}{\partial x}(x)f(x,u)\}<0\).

  • note that we can have local or ES CLFs too

theorem: consider a nonlinear system \(\dot x = f(x,u),x\in \mathbb{R}^n, u\in \mathbb{R}^m,f(0,0)=0\).
suppose \(f\) is Lipschitz continuous and \(\exists\) a CLF \(V:\mathbb{R}^n\rightarrow\mathbb{R}\) i.e. \(V\in C^1,V\) is pos. def., radially unbounded, and \(\inf_{u\in \mathbb{R}^m}\{\frac{\partial V}{\partial x}(x)f(x,u)\}<0\). then, \(\exists \alpha: \mathbb{R}^n\rightarrow \mathbb{R}^m\) that is infinitely differentiable (smooth, \(C^\infty\)) \(\forall x\not = 0\) s.t. \(\dot x = f(x,\alpha(x))\) is GAS.

  • if i can find a CLF, there exists \(\alpha\) which makes the system GAS.
  • proof is not constructive

definition: a control system of the form \(\dot x = f(x)+\Sigma^m_{i=1}g_i(x)u_i,x\in \mathbb{R}^n, u_i\in \mathbb{R}\) is a control affine nonlinear system (affine in \(u_i\))
\[\begin{align*} & u=\begin{bmatrix} u_1 \\ ... \\ u_m \end{bmatrix} \in \mathbb{R}^m \\ & \dot x= f(x) + g(x) u \\ &\rightarrow \in \mathbb{R}^n + \in \mathbb{R}^{nxm}\cdot\mathbb{R}^m \end{align*} \]
notation: {Lie derivative}
consider a function \(h: \mathbb{R}^n \rightarrow \mathbb{R}\) & let \(\dot x = f(x)\). then, \(L_f h(x):=\frac{\partial h}{\partial x}(x)f(x)\) is the Lie derivative of h with respect to f.

  • aka directional derivative

to combine: we have a control affine system \(\dot x = f(x)+\Sigma^m_{i=1}g_i(x)u_i\)
\[\begin{align*} & \dot V(x)=\frac{\partial V}{\partial x}(x)\{f(x)+\Sigma^m_{i=1}g_i(x)u_i\} \\ & = L_fV(x) + \Sigma L_{g_i}V(x)u_i \\ & \dot x = f(x) + g(x) u \\ & \dot V(x) = \frac{\partial V}{\partial x}\{f(x)+g(x)u\} \\ & = L_fV(x)+L_gV(x)u \end{align*} \]

claim: \(\forall x \not = 0, \inf_{u\in \mathbb{R}}\{L_fV(x)+L_gV(x)u\}<0\) \(\iff \forall x \not = 0, L_gV(x)=0 \implies L_f V(x)<0\)

proof: suppose \(L_g V(x)=0,\inf_u\{L_fV(x)+L_gV(x)u\}=\inf_u\{L_fV(x)\}<0 \iff L_f V(x) <0\)

alternatively, suppose
\(L_gV(x) \not = 0\text{ then, }\inf_{u\in \mathbb{R}}\{L_fV(x)+L_gV(x)u\}=-\infty<0\) because it can be anything

\(\dot x = f(x)+g(x)u, x\in \mathbb{R}^n, u\in \mathbb{R}\)
given CLF \(V(x)\{L_gV(x)=0\implies L_f V(x)<0\}\) assume is satisfied

  • then, how do we choose \(u=\alpha(x)\)
    \[u=\begin{cases} 0,& L_gV(x) = 0 & (\dot V=L_fV<0) \\ \frac{-L_fV-\varepsilon}{L_gV},&L_gV(x)\not = 0 & (\dot V = L_fV+L_gVu<0) \\ \mathbb{R}, & L_fV < 0 \end{cases} \]

    • note that \(u=0\) uses least amount of energy
    • note that \(\dot V =0 \implies\) SISL
      \[ u=\begin{cases} 0,&L_fV<0) \\ \frac{-L_fV-\varepsilon}{L_gV},&\text{else} \\ \end{cases} \iff u = \arg \min u^\top u \text{ s.t. }L_fV+L_gVu \le 0 \]
    • min-norm control minimizes the norm of u subject to the linear constraint of u
