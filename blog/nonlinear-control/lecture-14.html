finding CLFs:
\(\Sigma_{nl}:\dot x = f(x)+g(x)u,x\in\mathbb{R}^n,u\in \mathbb{R}^m\)
\(\Sigma_{lin}:\dot x = Ax+Bu,A=\frac{\partial f}{\partial x}|_{x_e,u_e},B=\frac{\partial g}{\partial x}|_{x_e,u_e}\)
LQR: \(J=\int^\infty_0 x^\top (t) Q x(t)+u^\top(t) R u(t) dt, Q>0,R>0\)
\(u=-kx\) and if (A,B) is stabilizable \(\implies k=R^{-1}B^\top P\)
\(P>0\) solves ARE: \(A^\top P + PA - PBR^{-1}B^\top P + Q =0\)
\(V(x)=x^\top P x\) is a CLF for the linear system \(\Sigma_{lin}\)
\(\implies V(x)\) is also a local CLF for \(\Sigma_{nl}\)

backstepping aka recursive feedback design

design a controller for the nonlinear system

\(\dot x = f(x)+g(x)u\)
\(u=\alpha(x),V(x)\)

\(\dot x = f(x)+g(x) \zeta\)
\(\dot \zeta = u\)

we need to design u, but we want to use the state feedback and stability proof
suppose we can compose \(\zeta\) directly, then \(\zeta = \alpha(x), V(x)\) but this is not possible with the given dynamics

we could choose \(u\) s.t. \(\zeta \rightarrow \alpha(x)\) as \(t \rightarrow \infty\)

  1. \(u = ?\)
  2. augmented CLF \(V_a(x,\zeta)=V(x)+?\)
    and then could we show that it works?

begin with linear system: \(\dot x_1 = x_2, \dot x_2 = u, x_e = 0,0\)
to drive eq. to the origin, we can design \(u=-c_1x_1-c_2x_2 \implies\)
\[\begin{bmatrix} \dot x_1 \\ \dot x_2 \end{bmatrix} = \begin{bmatrix} 0 & 1 \\ -c_1 & -c_2 \end{bmatrix}\begin{bmatrix} x_1 \\ x_2 \end{bmatrix} \]
if \(c_1,c_2>0,Re\{\lambda\}<0\)
assume \(x_2\) is a virtual control input. choose \(x_2=\alpha(x_1)=-c_1x_1,c_1>0\)
drive \(x_2\) to \(\alpha(x_1)\) because \(x_2\) cannot be arbitrarily specified. choose \(u\) s.t. \(x_2\rightarrow \alpha(x_1)\) as \(t\rightarrow \infty\).

can pick simple \(V_1(x)=\frac{1}{2}x_1^2\rightarrow \dot V_1(x)=x_1 \dot x_1=-c_1x_1^2<0\implies\) GAS
define error \(Z=x_2-\alpha(x_1)=x_2+c_1x_1\)
error dynamics: \(\dot z = \dot x_2 - \frac{\partial \alpha}{\partial x_1}\dot x_1=u+c_1x_2\)

\[\begin{bmatrix} x_1 \\ x_2 \end{bmatrix}\rightarrow \begin{bmatrix} x_1 \\ z \end{bmatrix} \]
\(\dot x_1 = z-c_1x_1, \dot z = u + c_1(z-c_1x_1)\)

augmented CLF candidate: \(V_a(x_1,z)=V_1(x_1)+\frac{1}{2}z_1^2=\frac{1}{2}x_1^2+\frac{1}{2}z_1^2\)
\(\dot V_a = x_1 \dot x_1 + z \dot z\)
\(= x_1[z-c_1x_1]+z\{u+c_1(z-c_1x_1)\}=-c_1x_1^2+z\{x_1+u+c_1(z-c_1x_1)\}\)
we want to design \(u\) s.t . the second term becomes \(-c_2z^2\)
\(u=-x_1-c_1(z-c_1x_1)-c_2z\)
\(V_a(x_1,x_2),u=\alpha(x_1,x_2) \leftarrow\) can formulate in original coordinates \(\implies\) GAS

nonlinear example: \(\dot x_1=x_1^2+x_2,\dot x_2=u\)
this system should suggest that we need to use backstepping

choose \(x_2\) as a virtual control input
\(x_2=\alpha(x_1)=-x_1^2-c_1x_1\) if we choose feedback linearization
\(V_1(x_1)=\frac{1}{2}x_1^2, \dot V_1 = x_1 \dot x_1 = -c_1x_1^2<0\implies\) GAS

backstepping: choose \(u\) to drive \(x_2 \rightarrow \alpha(x_1)\)
\(z=x_2-\alpha(x_1)=x_2+x_1^2+c_1x_1\)
drive \(z \rightarrow 0 \iff x_2 \rightarrow \alpha (x_1)\)
\(\dot x_1 = x_1^2+z-x_1^2-c_1x_1\)
\(\dot z = u + 2x_1[z-c_1x_1]+c_1[z-c_1x_1]=u+(2x_1+c_1)(z-c_1x_1)\)
find clf: \(V_a=V_1(x_1)+\frac{1}{2}z^2\)
\(\dot V_a=x_1(z-c_1x_1)+z\{u+(2x_1+c_1)(z-c_1x_1)\}\)
\(=-c_1x_1^2+z\{x_1+u+(2x_1+c_1)(z-c_1x_1)\}\)
\(u=-x_1-(2x_1+c_1)(z-c_1x_1)-c_2 z\)
\(\implies \dot V_a = -c_1x_1^2-c_2z^2<0\implies\) GAS
\[\begin{bmatrix} x_1 \\ z \end{bmatrix} \rightarrow 0 \iff \begin{bmatrix} x_1\rightarrow 0\\ x_2\rightarrow \alpha (x_1) \end{bmatrix} \implies \begin{bmatrix} x_1 \\ x_2 \end{bmatrix} \rightarrow 0 \] (requires \(\alpha(0)=0\))

assumption A1:
consider \(\Sigma: \dot x = f(x)+g(x)u,f(0)=0,f,g\) are Lipschitz, \(x \in \mathbb{R}^n, u \in \mathbb{R}^m\)
suppose \(\alpha: \mathbb{R}^n \rightarrow \mathbb{R}^m,\alpha \in C^1, \alpha(0)=0\) (feedback \(u=\alpha(x)\)) and \(V:\mathbb{R}^n\rightarrow \mathbb{R},V\in C^1,\) positive definite, radially unbounded s.t. \(L_fV(x)+L_gV(x)\alpha(x) \le -w(x),w\) is positive definite

integrator backstepping lemma:
suppose assumption A1 holds for \(\Sigma: \dot x = f(x)+g(x)u\). consider the system augmented with an integrator \(\Sigma_a:\dot x= f(x)+g(x)\zeta,\dot \zeta =u\). this tells us:

(i) if \(w(x)\) is positive definite, then \(\dot V\) is negative definite \(\rightarrow\) \(V_a(x,\zeta)=V(x)+\frac{1}{2}[\zeta-\alpha(x)]^2\) is a CLF for \(\Sigma_a\) which renders \((x,\zeta)=(0,0)\) is GAS
one such control is \(u=-c[\zeta-\alpha(x)]+\frac{\partial \alpha }{\partial x}(x)[f(x)+g(x)\zeta]-\frac{\partial V}{\partial x}(x)g(x), c>0\)

(ii) if \(w(x)\) is only positive semi-definite, then there exists a feedback which renders \(\dot V_a(x,\zeta)\le-w_a(x,\zeta)\le 0\) s.t. \(w_a(x,\zeta)>0\) when \(w(x)>0\) or \(\zeta \not = \alpha(x)\). this control provides SISL and convergence of \(x(t),\zeta(t)\) to \(z_a:=\{x,\zeta\}\in\mathbb{R}^{n+1}|w(x)=0,\zeta=\alpha(x)\).

example (revisited):
\(\dot x = f(x)+g(x)u=x^2+u\)
\(f(x)=x^2,g(x)=1\)
\(u=\alpha(x)=-x^2-c_1x,c_1>0\)
\(v=\frac{1}{2}x^2\implies \dot V = -c_1x^2\)
\(\Sigma_a = \dot x= f(x)+g(x)\zeta = x^2+\zeta, \dot \zeta = u\)
\(V_a(x,\zeta)=V(x)+\frac{1}{2}[\zeta+x^2+c_1x]\)
\(u=-c_2[\zeta+x^2+c_1x]+(-2x-c)[x^2+\zeta]\)
\(-x,c_2>0\)
makes the example easier to apply the lemma vs deriving it completely
