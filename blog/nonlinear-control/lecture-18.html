last time: feedback linearization
input-output feedback linearization

this time: feedback linearization continued

\(\Sigma_{NL}: \dot x = f(x)+g(x)u\)
this is feedback linearizable if

  1. exists input transformation that is state-based:
    • \(u=\alpha(x)+\beta(x)V\)
  2. state transformation
    • \(Z=T(x)\)
      \(x \in \mathbb{R}^n,u\in \mathbb{R}^m\)
      transform to \(\Sigma_{linear}:\dot z = Az+Bv\)
      assuming A and B are controllable

what systems are feedback linearizable?

if so, how do i find my input to state estimation (\(\alpha, \beta, T\))?

input-output linearization: (for SISO)
\(\dot x= f(x)+g(x)u, x\in \mathbb{R}^n, x\in\mathbb{R}\)
\(y = h(x), y \in \mathbb{R}\)
output dynamics:
\(\dot y = \frac{d}{dt}h(x)=\frac{\partial h}{\partial x}[f(x)+g(x)u]=L_fh(x)+L_gh(x)u\)
if \(L_gh(x)\not = 0\)
I can now design controller u to convert in/out dynamics to linear system:

choose u = \(L_gh(x)^{-1}[-L_fh(x)+v]\implies \dot y = v\)
if \(L_gh(x)=0,\dot y = L_fh(x)\)
\(\ddot y = \frac{\partial L_fh}{\partial x}[f(x)+g(x)u]=L_f(L_fh)+L_f(L_gh)u\)
\(=L_f^2h(x)+L_gL_fh\)
if \(L_gL_fh(x)\not =0,\) choose \(u=L_gL_fh(x)^{-1}[-L_f^2h(x)+v]\implies \ddot y = v\) (2nd order linearization through IO dynamics)

if h(x) is s.t. \(L_gh(x)=0,L_gL_fh(x)=0,...,L_gL_f^{r-2}h(x)=0\)
and \(L_gL_f^rh(x)\not = 0\)
\(y^r=L_f^rh(x)+L_gL_f^{r-1}h(x)u\)
this means \(\dot y,\ddot y, ...,y^{r-1}\) does not depend on u, but \(y^r\) depends on u

choose \(u=L_gL_f^{r-1}h(x)^{-1}[-L_f^rh(x)+v]\implies y^r=v\)(rth order linear IO dynamics)
r is the relative degree of \(y=h(x)\)

when r=n, IO linearization becomes feedback linearization
questions depend on if we can find y=h(x) output with degree n
then we can find \(\alpha, \beta, T\)

define relative degree
SISO system \(\dot x = f(x)+g(x)u,y=h(x),x\in \mathbb{R}^n, y \in \mathbb{R}, y \in \mathbb{R}\)
is said to have a relative degree \(r\) at \(x_0\in X\) if
(1) \(\forall 0 \le k < r-1, \space L_gL_f^kh(x)=0, \forall x\) in the neighborhood of \(x_0\)
(2) \(L_gL_f^{r-1}h(x)\not =0\)

example 1:
\(\dot x_1 = x_2, \dot x_2 = -x_1^3+u, y =x_1\)
\(h(x) = x_1 \dot y = \dot x_1, = x_2, \ddot y = \dot x_2 = -x_1^3+u\)
\(\therefore r=2\) because \(\ddot y\) contains u

example 2:
\(\dot x_1 = x_2+x_3^3, \dot x_2 = x_3, \dot x_3=u, y = x_1\)
\(r=2\)

for the relative degree at any point \(x_3\not =0\) (in the neighborhood), but at the origin where \(x_3=0\), there is not a well-defined degree \(\rightarrow\) depends on the origin.

example 3: SISO linear system
\(\dot x = Ax+Bu,y=Cx\)
\(f(x)=Ax, g(x)=B,h(x)=Cx\)
\(\dot y = L_fh+L_ghu\)
\(L_fh=\frac{\partial h}{\partial x}f(x)=CAx\)
\(L_gh=\frac{\partial h}{\partial x}g(x)=CB\)
\(CB \not = 0 \implies r=1\)
if \(CB=0,\ddot y = CA^2x+CABu\)
if \(CAB \not =0 \implies r =2\)
if \(CB=0,CAB=0,\dots,CA^{r-1}B=0,CA^{r-1}B\not=0\implies\) relative degree

\(\dot x = f(x)+g(x)u,y=h(x),x\in\mathbb{R}^n, u,y\in \mathbb{R}\)
\(y=h(x)\) has rel. degree r \(y^r=L_f^rh(x)+L_gL_f^{r-1}h(x)u\)
\(u=L_gL_f^{r-1}h(x)^{-1}[-L_f^rh(x)+v]\implies y^r\)=v (rth order ODE)

choose states
\[z=\begin{bmatrix} y \\ \dot y \\ \vdots \\ y^{r-1} \end{bmatrix}\in \mathbb{R}^r \]

\[\dot z = \begin{bmatrix} 0 & 1 & & & \\ & 0 & 1 & & \\ & & 0 & 1 & \\ & & & \vdots & ...\\ \end{bmatrix}z + \begin{bmatrix} 0 \\ 0 \\ \vdots \\ 1 \end{bmatrix}v \]

(A,B) is controllable
choose linear control \(v=-kz\) s.t. \(\dot z=(A-Bk)z,Re\{\lambda_i(A-Bk)\}<0)\)
\(v=-k_1h(x)-k_2L_fh(x)-...-k_rL_f^{r-1}h(x)\)
\(\implies z(t)\rightarrow 0\) as \(t \rightarrow \infty\), \(y(t)\rightarrow 0\)

does this implies that the state goes to the origin?

  • this depends on the remaining dynamics

\(Z=\{x|h(x)=L_fh(x)=...=L_f^{r-1}h(x)=0\}\)
\(y = \dot y = ... = y^{r-1}=0, z\in Z, z_0=0\)

choice of u & v do the following:
(1) create Z surface
(2) make Z attractive
(3) make Z invariant

u & v render Z invariant & attractive
x \(\rightarrow\) 0 if dynamics on Z are stable (minimum-phase)

how do i find the zero dynamics? (restricted to staying on Z)
\(z=0 \iff y = \dot y = \dots \ y ^{r-1}=0 \implies v =0\)
\(u=-L_gL_f^{r-1}h(x)^{-1}L_f^rh(x)\)

example:
\(\dot x_1 = x_2, \dot x_2 = \alpha x_3+u, \dot x_3 = \beta x_3 + u\)
\(y=x_1\)
rel. degree r =2
find zero dynamics
on Z, \(y=x_1=0, \dot y = x_2=0\)
\(u^*=-\alpha x_3 (\ddot y =0)\)
zero dynamics: \(\dot x_3 = (\beta + \alpha)x_3\)
if \(\alpha + \beta < 0 \implies\) stable zero dynamics (min phase)
\(\implies x(t) \rightarrow 0\) as \(t \rightarrow \infty\)

for a linear system, \(\frac{s-(\alpha+\beta)}{s^2(s-\beta)}\) compare to relative degree to poles and zeros
