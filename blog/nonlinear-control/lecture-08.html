Chetaev's instability theorem:
suppose \(\dot x - f(x), f(x_e)=0\). suppose \(\exists D\) containing \(x_e\) on which f is locally Lipschitz & \(\exists V:D \rightarrow \mathbb{R},V\in C^1\) s.t.
(a) \(V(0)=0\)
(b) \(\forall \delta > 0, \space \exists x_0 \in B_\delta(0)\) s.t. \(V(x_0)>0\)
(c) \(\exists \varepsilon > 0\) s.t. \(\dot V(x)\) on \(U \triangleq \{x \in B_\varepsilon(0)|V(x)>0\}\subset D\)
then, \(x_e=0\) is unstable.

recall definition for instability via Lyapunov

example 1:
\(\dot x_1=x_1,\dot x_2=x_2\)
candidate \(V(x)=1/2x_1^2+1/2x_2^2>0,x\not = 0\)
\(\dot V(x_1,x_2)=x_1^2+x_2^2>0\implies x=0\) is unstable

example 2:
\(\dot x_1=-x_1,\dot x_2=x_2\)
candidate \(V(x)=1/2x_1^2+1/2x_2^2>0,x\not = 0\)
\(\dot V(x_1,x_2)=-x_1^2+x_2^2\implies\) cannot conclude definiteness
candidate \(V_1(x)=-1/2x_1^2+1/2x_2^2\)
\(\dot V_2(x_1,x_2)=x_1^2+x_2^2>0,x\not=0\implies x=0\) is unstable via Chetaev's

linearization and quadratic Lyapunov functions
linear \(\dot x = Ax,x\in \mathbb{R}^n\)
defn: \(V(x)=x^\top Px,P\in \mathbb{R}^{nxn}\) is a quadratic form
\(P=\frac{P+P^\top}{2}+\frac{P-P^\top}{2}\)
= symmetric component + asymmetric component

  • note: \(M \in \mathbb{R}^{nxn}\) is symmetric if \(M^\top=M\) and antisymmetric if \(M^\top=-M\)
    \(V(x)=x^\top Px=x^\top(\frac{P+P^\top}{2})x\)
  • check: \(x^\top(\frac{P-P^\top}{2})x=0\)
  • \(x^\top(\frac{P-P^\top}{2})x=x^\top(\frac{P^\top-P}{2})x=0\implies\)LHS=RHS=0
  • we must assume P is symmetric

def: \(V(x)=x^\top P x\) is positive definite if \(x^\top P x>0,x\not=0\iff P\) is positive definite \(\iff P>0\)

  • fact: if \(P=P^\top,P>0\iff \lambda_i(P)>0\). aka if P is symmetric and positive definite, all eig. values are real and positive.
    def: \(Q=Q^\top\) is negative definite if \(-Q>0\) aka -Q is positive definite.
  • \(-Q>0\iff \lambda_i(Q)<0\)
    this means we can check eig. values for positive definiteness.
  • we can also check leading principal minors > 0

theorem: given an nxn matrix with real entries, the following are equivalent:

  1. all eig. values of A have negative real parts
  2. there exists some (1+) positive definite Q s.t. \(A^\top P + PA = -Q\) has a solution P that is unique and positive definite (P>0)
  3. for any positive definite Q (Q>0), \(A^\top P + PA = -Q\) has a unique solution P>0.
    corollary: \(\dot x=Ax\) has a GAS eq. pt. \(\iff \exists\) quadratic lyapunov function \(V(x)=x^\top Px,P>0\) s.t. \(\dot V = x^\top[A^\top P + PA]x\) is negative definite.
    \(\implies \dot V = \dot x^\top P x + x^\top P \dot x = x^\top A^\top P x + x^\top P A x = x^\top[A^\top P + P A]x<0\)

Lyapunov equation: \(A^\top P + PA = -Q\)

  • to find V(x) for \(\dot x = Ax\): pick Q>0, Q=I
  • we can find P by solving the equation
  • we can then construct \(V(x)=x^\top P x \implies \dot V(x)=-x^\top Q x<0\)

linearization: \(\dot x = f(x),f(x_e)=0,f\in C^1\), \(A=\frac{\partial f}{\partial x}|_{x=x_e}\)

  • linearization: \(\dot {\bar x} \approx A \bar x,\bar x = x-x_e\)
  • if \(x_e=0\) then \(\bar x = x\)
  • apply taylor series for f(x) about \(x_e\), \(f(x)=f(0)+Ax+R(x)\)
  • \(R(x)\) satisfies \(\lim_{||x|||\rightarrow 0}=\frac{||R(x)||}{||x||}=0\)
  • this means that \(R(x)\) satisfies \(\forall r>0, \exists \sigma>0\) s.t. \(x \in B_\sigma(0)\implies ||R(x)|| \le r||x||\)
  • cauchy schwartz inequality: \(\forall xy \in \mathbb{R}^n,x\top y \le |x\top y|\le||x||_2\cdot ||y||_2\)

prove lyapunov indirect method: (this is a justification of linear control)

consider \(\dot x = f(x),f(x_e)=0,f\in C^1\)

  1. if the linearization of the system about \(x_e\) has eig. values with negative real parts, then we know the linear system is stable. in addition, \(x_e\) is asymptotically stable for \(\dot x = f(x)\) locally.
  2. if the linearization has 1+ eig. value with a positive real part, then the linear system is unstable. in addition , \(\dot x = f(x)\) is unstable for \(x_e\).
  3. if the linearization has all eigenvalues with real components \(\le 0\) and at least one real part \(=0\), the linear system is stable. there is no conclusion regarding the nonlinear system.

proof:
will show (3) and (1).
3 \(\rightarrow\) \(\dot x = x^3, \dot x = -x^3\rightarrow\) unstable and GAS

  • the first is unstable because it will go to infinity with positive x. the second will stay at the origin.
  • \(A=\frac{\partial f}{\partial x}|_{x_e}=3x^2=0\implies\) eigenvalues are 0.

1 \(\rightarrow\) assume \(x_e=0\)
\(A=\frac{\partial f}{\partial x}|_{x_e},Re\{\lambda_i\}<0\)
\(\implies P>0,\) s.t. \(A^\top P + PA = -I\)
choose candidate function: \(V(x)=x^\top P x > 0, x\not = 0\)

  • \(\dot x = f(x) = Ax + R(x)\)
  • \(\dot V = \dot x^\top P x + x^\top P \dot x=[ax+R(x)]^\top Px+x^\top P[ax+R(x)]\)
  • = \(x^\top[A^\top P + PA]x+R(x)^\top Px+x^\top P R(x)=-x^\top x+2x^\top P R(x)\)

note: \(x^\top P R(x)\le|x^\top P R(x)|\rightarrow \text{ cauchy-schwartz } \le ||x||_2 \cdot ||PR(x)||_2\)

  • \(\le ||x||_2 \cdot ||P||_2 ||R(x)||_2\)
  • \(\forall r>0,\exists \delta>0\) s.t. \(||x||<\sigma \implies ||R(x)||\le r||x||\)
  • \(\implies x^\top P R(x) \le r||P||_i \cdot ||x||_2^2\) when \(||x||<\sigma\)
  • back to \(\dot V: \dot V(x) \le =x^\top x+ 2r||P||_i \cdot ||x||_2^2\) when \(||x||<\sigma\)
  • = \(-(1-2r||P||_i)x^\top x\)
  • choose r to make \(1-2r||P||_i>0 \rightarrow \frac{1}{2||P||_i}\implies \dot V<0\) for A.S. when \(||x||<\sigma\)
