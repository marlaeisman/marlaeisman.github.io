Nonlinear Control Notes · Apr 21, 2026

FB linearization theorem:
\(\Sigma \dot x = f(x) +g(x)u\) is FB linearizable iff
(a) \([g(x), \text{ad}_fg(x), ..., \text{ad}^{nn-1}_fg(x)]\) has rank n \(\forall x\).
(b) \(\Delta=\text{span}\{g(x),\text{ad}_fg(x), ..., \text{ad}^{n-2}_fg(x)\}\) is involutive

proposition: \(\Sigma\) has relative degree n at x iff satisfies:
(1) \(L_gh = L_gL_fh=...=L_gL_f^{n-2}h(x) =0\)
(2) \(L_gL_f^{n-1} \not =0\)
\(\iff\)
(3) \(L_gh=L_{\text{ad}_fg(x)}h=...=L_{\text{ad}^{n-2}_fg(x)}h=0\)
(4) \(L_{\text{ad}_fg(x)}h(x) \not = 0\)

can write (3) and (4) as
(3) \(\iff (5) \frac{\partial h}{\partial x}[g(x) \text{ad}_fg(x) ... \text{ad}^{n-2}_fg(x)]=0\)

solution \(h(x)\) to PDE in (5) exists if the distribution defined as \(\Delta := \{g,\text{ad}_fg(x),...,\text{ad}^{n-2}_fg(x)\}\) is involutive (Frobenius Theorem).

proof (FB Lin. theorem):
given (a) and (b), show \(h(x)\) exists with relative degree r=n
\(\Delta(x)\) (defined in (a) and (b)) is involutive (by (b)) and nonsingular (by (a)) and has full rank.
\(\Delta\) involutive \(\implies\) (5) i.e. \(\exists h(x), \frac{\partial h}{\partial x} \not = 0, \frac{\partial h}{\partial x}[g(x), ..., \text{ad}^{n-2}_fg(x)]=0\)
need to show that h(x) satisfies (4) thru proof by contradiction:
assume \(L_{\text{ad}^{n-1}_fg(x)}=0\)
then, \(\frac{\partial h}{\partial x}[g(x), ..., \text{ad}^{n-2}_fg(x),\text{ad}^{n-1}_fg(x)]=0\)
\(\implies \frac{\partial h}{\partial x}=0\) is a contradiction

example:
\[\dot x = \begin{bmatrix} a\sin x_2 \\ -x_1^2 \end{bmatrix} + \begin{bmatrix} 0 \\1 \end{bmatrix} \]
is the system FB linearizable?
if so, find h(x)

\[\text{ad}_fg(x)=[f,g]=\begin{bmatrix} -a\cos x_2 \\ 0 \end{bmatrix} \]
\[[g,\text{ad}_fg]=\begin{bmatrix} 0 & -a \cos x_2 \\ 1 & 0 \end{bmatrix} \] is rank 2 \(\forall x\) s.t. \(\cos x_2 \not = 0\)
\(\Delta = \text{span}\{g\}\) is involutive
\(\implies\) FB linearizable \(\forall x\) s.t. \(\cos x_2 \not = 0\)

find h(x) s.t. \(\frac{\partial h}{\partial x}g(x)=0, \frac{\partial L_fh}{\partial x}g(x) \not = 0\)
\(\frac{\partial h}{\partial x_2}=0 \implies h\) is independent of \(x_2\)
\(L_fh=\frac{\partial h}{\partial x_1}a\sin x_2\)
\(\frac{\partial L_fh}{\partial x}g=\frac{\partial L_fh}{\partial x_2}=\frac{\partial h}{\partial x_1}a\cos x_2 \not = 0\)
pick h that is independent and keeps term nonzero
\(h(x) = x_1\) and evaluate to be nonzero given previous conditions
could also pick \(h(x)=x_1^5\)

MIMO (square) systems:
\(\Sigma: \dot x = f(x) + \sum^n_{i=1}g_i(x)u_i\)
\(y = [h_1(x) \dots h_m(x)]^\top=h(x)\)
\(g(x)=[g(x),\dots, g_m(x)], u = [u_1 \dots u_m]^\top\)

look at I/O first
how do we define relative degree?

vector relative degree:
\(\Sigma\) has vector relative degree (\(r_1, r_2, ..., r_m\)) at \(x_0\) if
(a) for all \(1 \le j \le m, 1 \le i \le m, 0 \le k < m\), \(L_{g_j}L_f^kh_i(x)=0,\forall x\) in nbd of x
(b) the mxm matrix (decoupling matrix)
\[A(x)=\begin{bmatrix} L_{g_1}L_f^{n_i-1}h_1(x) & \dots &L_{g_m}L_f^{n_i-1}h_1(x) \\ \vdots \\ L_{g_1}L_f^{n_n-1}h_m(x) & & L_{g_m}L_f^{n_m-1}h_m(x) \end{bmatrix} \] is nonsingular at \(x_0\)

\(\implies y_i^{n_i}=L_f^{r_i}h_i(x)+L_{g_1}L_f^{r_i-1}h_i(x)u_i+\dots+L_{g_m}L_f^{r_i-1}h_i(x)u_m\)
\(= L_f^{r_i}h_i(x) + \sum_j L_{g_j}L_f^{r_1-1}h_i(x)u_j\)
at least one \(L_{g_j}L_f^{r_1-1}h_i(x)u_j \not = 0 \forall i\)
IO dynamics:
\([y_i^{r_1}\dots y_m^{r_m}]\top=[L_f^{r_1}h_1\dots L_f^{r_m}h_m]^\top+A(x)u\)

  • y equation for each output

MIMO IO lin:
choose \(u(x)=A^{-1}(x)\{-L_fh(x)+v\}\)
\(\implies [y_i^{r_1}\dots y_m^{r_m}]\top=v\)
linearized for control

number of states in IO dynamics: \(r_1 + \dots + r_m\)
if \(r_1+\dots+r_m <n \implies\) IO lin

  • use v to drive \(y \rightarrow 0\) (has internal dynamics)
    if \(r_1+\dots+r_m =n \implies\) feedback lin
    if zero dynamics are exp stable, \(x \rightarrow 0\)
