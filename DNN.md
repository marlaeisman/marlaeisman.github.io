# Adaptive Multi-Agent Herding With Deep Neural Networks (2023–2024)

**Summary:**
Created a simulation environment and analysis framework to study coordination and control in multi-agent herding tasks, leveraging deep neural networks (DNNs) for adaptive strategy learning and outdoor real-time experiments.

**Key results:**
- Implemented a recursive Python framework enabling systematic parameter sweeps (neural depth, learning rate, activation functions) and automated logging of error curves and convergence metrics used for quantitative comparison.
- Demonstrated real-time outdoor learning experiments and validated learned strategies against physics-based baselines.

**Technical details:**
- Implementation: Python, NumPy, PyTorch, and a custom simulator for multi-agent dynamics; scripts for reproducible experiments and visualization of convergence and error metrics.
